# 🏋️‍♂️ Sistema de Academia - Praticando POO com Java

Este projeto foi desenvolvido para fixar os conceitos fundamentais de **Programação Orientada a Objetos (POO)** em Java, utilizando uma analogia prática com a montagem de treinos de academia.

## 🚀 Evolução do Código

1. **Multiplicação de Objetos:** Inicialmente, os atributos de cada exercício eram preenchidos linha por linha na classe principal (`Academia.java`).
2. **Otimização com Construtor:** Implementação de um construtor na classe `Exercicio.java`, eliminando o "volume inútil" do código e reduzindo a criação de cada objeto de 4 linhas para apenas 1 linha.

## 🛠️ Tecnologias Utilizadas
* **Java** (JDK atualizado)
* **IntelliJ IDEA**
